# NGFW(Next Generation Firewall) 완전한 설계 문서 작성
## 설계 원칙
- 자체 구현: 외부 의존 관계 최소화 (부트로더, Linux Kernel만 활용)
- C 언어 중심 : 모든 핵심 기능 C로 직접 구현, 코드내 주석은 모두 영문으로 통일, 코딩 스타일 GNU스타일
- 빌드 통일 : GNU Make, Autotools, Shell script 중심 표준화
- 가시성 확보 : 빌드->설치->실행->모니터링 전체 트러블 슈팅 지원 및 selftest 로 모든 기능 스스로 검증 가능한 수준
- 플랫폼 이식 : 다양한 플랫폼 이식성 지원
- 사용자 경험 : 사용 편의, 직관성, 안정성, 성능 최우선
- 구조적 설계 : 명확한 모듈화, 느슨한 결합, 인터페이스 표준화, 이미 있는 구현에서 파편화된 구조를 추가로 만들지 말고 구조화 할 것.
- 계층적 설계 : 관심사 분리, 명확한 레이어 경계, 재사용성
- 확장성 : 수평/수직 확장 지원, 플러그인 아키텍처, 미래 요구 대응
- 표준 준수 : 모든 표준 충족
- 기능의 범위 : 모든 NGFW의 풀 기능 수용 및 구현, 타사 제품과 호환, 고성능 만족, 낮은 리소스 요구사항 만족, 다양한 오프로딩 지원
- 커널 모듈 구현 : 커널 모듈 구현은 커널의 알려진 관례 및 규칙을 최대한 따라서 구현,  커널 버전 6.12이상의 모든 커널 버전에 호환될 수 있도록 구현
## 설계 문서 위치
